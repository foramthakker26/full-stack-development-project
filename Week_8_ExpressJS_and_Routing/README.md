# Week 8 - Express.js and Routing

## Objective
To learn Express.js fundamentals and understand routing in a Node.js application.

## How to Run

Open this folder in VS Code and run:

```bash
npm install
npm start
```

Open:

```text
http://localhost:3000
```

## API Routes

GET /api

GET /api/users
GET /api/users/:id

GET /api/products
GET /api/products/:id

## Concepts Covered
- Express server setup
- Middleware
- JSON responses
- Route handling
- Route parameters
- Express Router
- Static file serving
- 404 handling

## Conclusion
The Week 8 task demonstrates Express.js server creation, modular routing, route parameters, JSON responses, and frontend-to-backend API requests.
