# Week 2 - Components & Props

## Objective
Practice creating reusable React components and passing data using props.

## What is demonstrated?
- Functional React components
- Reusable components
- Passing string props
- Passing multiple props
- Destructuring props
- Default prop value
- Rendering multiple cards using `map()`
- Parent-to-child data flow

## Run the project

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Main files
- `src/App.jsx` - parent component and data
- `src/components/Header.jsx` - Header component using props
- `src/components/StudentCard.jsx` - reusable student card
- `src/components/CourseCard.jsx` - course card with a default prop
- `src/components/Footer.jsx` - Footer component using props
