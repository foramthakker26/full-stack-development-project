# Week 6 - Advanced React Hooks

This project demonstrates commonly used advanced React Hooks.

## Hooks covered

- `useState`
- `useEffect`
- `useMemo`
- `useCallback`
- `useRef`
- `useReducer`
- Custom Hook: `useDocumentTitle`

## Run the project

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Project structure

- `index.html` - application entry HTML
- `src/main.jsx` - React entry point
- `src/App.jsx` - Advanced Hooks examples
- `src/App.css` - styling
- `vite.config.js` - Vite configuration
